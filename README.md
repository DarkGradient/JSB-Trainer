Не просто чит, а в некотором уже роде мод меню.

Создано при помощи вайбкода.

Де-компилированный код игры не предоставляю.
Для компиляции требуется установленный melonloader версии 0.7.3.

Пути по умолчанию используют linux вариант, замените на свой.
Для linux версия игры должна быть proton, чтобы корректно работало не забудте WINEDLLOVERRIDE на version, либо через protontricks.
