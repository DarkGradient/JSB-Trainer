# JS&B Extra Stuff — Trainer & Mod Menu

Тренировочное мод-меню и трейнер для **Just Shapes & Beats** на базе **MelonLoader (v0.7.3+)**. Разработан для кастомизации визуала, QoL-улучшений и добавления новых геймплейных механик.

---

## ⚡ Основные возможности

- **Визуал и Графика:** Custom Player & Enemy Color (HSV / RGB), Full Power Trail, Deltarune Grid BG, восстановление размера клеток анимаций стен, Always Black BG, скрытие таймлайна, FPS Unlock (400 FPS).
- **Геймплей и Режимы:** Mouse Control, Noclip, Auto-Dash, кастомный кулдаун дэша, Orange SOUL Mode, Purple SOUL Mode, One-Hit Mode (включая True One-Hit), Фонарик.
- **Интерфейс и Управление:** Крупное IMGUI-меню (`[K]`), фоновая интеграция DualShock 4 (Lightbar + вибрация).

---

## 🐧 Запуск на Linux / Steam Deck (Proton)

Для корректной загрузки MelonLoader через Proton задайте переменную окружения в параметрах запуска игры в Steam:

```bash
WINEDLLOVERRIDES="version=n,b" %command%
```

*(Или настройте переопределение DLL `version` через Protontricks).*

---

## 🛠 Сборка и Установка

1. Установите **MelonLoader 0.7.3+** в директорию игры.
2. Скопируйте скомпилированный `.dll` файл в папку `Mods/`.
3. В игре нажмите **`[K]`** для вызова меню настроек.
