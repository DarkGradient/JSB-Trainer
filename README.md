# Дисклеймер

Добро пожаловать. Настоящее программное обеспечение представляет собой тренировочное модификационное меню (trainer / mod menu) для игры Just Shapes & Beats. Оно создано для расширения игрового опыта и включает:

- функции повышения удобства (QoL): разблокировка FPS, пропуск интро, управление скоростью музыки, скрытие таймлайна, улучшения контроллера, пауза в мультиплеере и другие;
- игровые режимы (Gamemodes): noclip, one-hit, flashlight, управление мышью, Orange Soul, Purple Soul;
- дополнительные и экспериментальные модули: визуализатор аудио, отрисовка хитбоксов, авто-дэш, изменение фона и прочие.

Значительная часть функционала предназначена для использования в одиночной игре, а также в закрытых сессиях с друзьями. Разработка велась преимущественно методом vibe-coding. Надеюсь, что данное меню поможет вам комфортнее проходить уровни, экспериментировать и получать удовольствие от игры.

Поскольку отдельные функции (noclip, one-hit и подобные) могут быть использованы в качестве средств читерства, необходимо прямо и однозначно заявить: данное меню не должно применяться для ухудшения игрового опыта других участников. Многие игроки обращаются к игре после продолжительного рабочего или учебного дня исключительно с целью спокойного времяпрепровождения. Применение мощных функций в публичных сессиях лишает таких людей возможности получить удовольствие и портит им день. Если этого аргумента недостаточно, следует учитывать, что злоупотребление модификациями в злонамеренных целях может повлечь наложение санкций на ваш игровой аккаунт.

Декомпилированный исходный код игры не предоставляется и не распространяется. Для компиляции требуется установленный MelonLoader версии 0.7.3. Пути по умолчанию указаны в варианте для Linux; пользователь обязан самостоятельно заменить их на пути, соответствующие своей системе.

При использовании в среде Linux игра должна запускаться через Proton. Для корректной загрузки MelonLoader необходимо установить переменную окружения строго в следующем виде:  
`WINEDLLOVERRIDES="version=n,b"`  
Либо задать её через параметры запуска Steam (`WINEDLLOVERRIDES="version=n,b" %command%`), либо выполнить соответствующую настройку посредством protontricks. Использование иных значений данной переменной может привести к неработоспособности модификации.
