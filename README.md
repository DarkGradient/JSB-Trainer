# Дисклеймер

Добро пожаловать. Настоящее программное обеспечение представляет собой модификационное меню (mod menu), предназначенное для расширения игрового опыта. Оно включает функции повышения удобства, возможности для неформального взаимодействия в закрытой группе друзей, а также средства защиты лобби от вредоносных действий других игроков. Значительная часть функционала относится к категории развлекательных (trolling) возможностей, поскольку разработка велась преимущественно для использования в частных лобби совместно с друзьями. Надеюсь, что вы и участники ваших игровых сессий также сможете получать удовольствие от применения данного меню как в целях развлечения, так и для защиты от недобросовестных игроков.

Поскольку отдельные функции могут быть использованы в качестве средств читерства, необходимо прямо и однозначно заявить: данное меню не должно применяться для ухудшения игрового опыта других участников. Многие игроки обращаются к игре после продолжительного рабочего или учебного дня исключительно с целью спокойного времяпрепровождения. Применение меню для разрушения лобби лишает таких людей возможности получить удовольствие и портит им день. Если этого аргумента недостаточно, следует учитывать, что злоупотребление модификациями в злонамеренных целях может повлечь наложение санкций на ваш игровой аккаунт.

Программное обеспечение создано методом vibe-coding. Декомпилированный исходный код игры не предоставляется и не распространяется. Для компиляции требуется установленный MelonLoader версии 0.7.3. Пути по умолчанию указаны в варианте для Linux; пользователь обязан самостоятельно заменить их на пути, соответствующие своей системе.

При использовании в среде Linux игра должна запускаться через Proton. Для корректной загрузки MelonLoader необходимо установить переменную окружения строго в следующем виде:  
`WINEDLLOVERRIDES="version=n,b"`  
Либо задать её через параметры запуска Steam (`WINEDLLOVERRIDES="version=n,b" %command%`), либо выполнить соответствующую настройку посредством protontricks. Использование иных значений данной переменной может привести к неработоспособности модификации.
